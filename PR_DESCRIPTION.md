## Инструкция по быстрому запуску (быстрой проверке)

1. `git clone <ссылка на форк> && cd QrMobileApp && git switch solution/varfolomeeva`
2. `./gradlew :receipt-core:test` (Windows: `./gradlew.bat :receipt-core:test`)
3. `./gradlew :app:installDebug` (Windows: `./gradlew.bat :app:installDebug`)

Требуются JDK 17, Android SDK Platform 35 и Android-телефон или эмулятор API 24+. Подробности и ограничения — в разделе 12 README.
