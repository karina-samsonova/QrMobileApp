## Выполненное задание

Android/Kotlin, этапы 1–5: CameraX, фискальный QR (ML Kit), OCR на фото (Tesseract `rus+eng` и ML Kit), позиции и сверка, подсветка QR/итога на превью, переключатель движка и офлайн-история SQLite без дублей. Разбор и сверка вынесены в независимый модуль `:receipt-core`.

## Видео

Видео записывается отдельно по строгому сценарию [`VIDEO_SCRIPT.md`](VIDEO_SCRIPT.md). Ссылка на запись пока отсутствует. По критериям задания без видео работа не считается завершённой для сдачи; PR открыт как черновик, чтобы код и замеры можно было проверить заранее.

## Что сделано

- [x] Этап 1 — камера, чтение и валидация фискального QR.
- [x] Этап 2 — фото с камеры или галереи, OCR итога и даты, исходные строки.
- [x] Этап 3 — товары, количество, цена, сумма, сверка и понятный статус.
- [x] Этап 4 — рамки QR и итога на превью; сравнительные замеры на пяти предоставленных образцах.
- [x] Этап 5* — SQLite-история, обновление повторного чека, Tesseract и ML Kit с переключателем.

`./gradlew.bat :receipt-core:test :app:assembleDebug`: `BUILD SUCCESSFUL`, 30/30 тестов. APK установлен и запущен на эмуляторе Android API 35. Чеки №2–5 дали четыре записи в истории; повторное сканирование №2 не создало дубль. Подробные результаты и снимки экрана: [`verification/README.md`](verification/README.md).

Живую подсветку на физической камере следует показать при записи видео.

## Инструкция по быстрому запуску

1. `git clone https://github.com/switerElly/QrMobileApp.git && cd QrMobileApp && git switch solution/varfolomeeva`
2. `./gradlew.bat :receipt-core:test :app:assembleDebug` (macOS/Linux: `./gradlew`)
3. `./gradlew.bat :app:installDebug`; открыть приложение и меню «Открыть образец чека».

Требуются JDK 17, Android SDK Platform 35 и устройство или эмулятор API 24+. Подробности — в разделе 12 README.
