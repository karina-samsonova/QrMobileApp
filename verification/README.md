# Проверка на Android-эмуляторе

Проверка выполнена 03.11.2026 на эмуляторе Android API 35. Каждый из пяти предоставленных файлов открыт через меню «Открыть образец чека» в установленном debug APK. Основной движок — Tesseract (`rus+eng`); приложение параллельно измеряет ML Kit. Числа ниже считаны с экранов приложения, исходные UI-дампы и [снимки экрана](emulator/) сохранены рядом. Время относится к одному прогону на данном эмуляторе и не является оценкой производительности телефона.

## Этап 5: сравнение двух OCR-движков

| Образец | ML Kit: верный итог | Позиции ML Kit | ML Kit, мс |
|---|---|---:|---:|
| 1 | нет | 0/4 | 2612 |
| 2 | нет | 0/2 | 2991 |
| 3 | нет | 1/1 | 2294 |
| 4 | нет | 1/1 | 2972 |
| 5 | нет | 0/1 | 2653 |

Tesseract нашёл верный итог у четырёх из пяти образцов; ML Kit в этой серии не выделил ни одного итога. Все четыре фискальных QR обнаружены, для малого QR на чеке №5 понадобился повторный проход по увеличенному фото. У чека №3 Tesseract распознал одну позицию, итог и QR, поэтому получен полный положительный результат. Для чека №2 итог найден, но OCR-дата не совпала с QR и одна из двух позиций потеряна; приложение вывело предупреждение. Маленькие изображения и русский текст заметно снижают надёжность обоих подходов.

## Проверка сборки и истории

- `:receipt-core:test :app:assembleDebug` — `BUILD SUCCESSFUL`; 30 тестов Kotlin-модуля прошли.
- APK установлен через `adb install -r` и запущен на эмуляторе; поиск QR на фотографиях и оба OCR-движка выполнены внутри приложения.
- Чеки №2–5 создали четыре записи SQLite. Повторная обработка №2 показала «Повторный чек обновлён без дубля»; [история](emulator/history.png) по-прежнему содержит четыре записи после перезапуска приложения.
- Выбор ML Kit в настройках проверен: заголовок основного результата сменился на `Основной OCR: ML Kit`.

Снимки [№1](emulator/check1.png), [№2](emulator/check2.png), [№3](emulator/check3.png), [№4](emulator/check4.png), [№5](emulator/check5.png) показывают фактические результаты. XML-дампы экрана сохранены с теми же именами для проверки текста и чисел. Живую подсветку QR и итога на превью нельзя подтвердить по проверке фото; для этой части нужна съёмка физического экрана телефона во время наведения камеры на чек. Пять файлов были предоставлены для задачи, но факт, что это чеки личных покупок, не подтверждён; это ограничение критерия «пять своих чеков» остаётся явным.
