# Публичные примеры чеков

Изображения в этой папке скачаны из открытого набора [cdek-ocr/receipt-ocr-ru](https://huggingface.co/datasets/cdek-ocr/receipt-ocr-ru) (лицензия MIT). Они предназначены для ручной проверки через кнопку «Выбрать фото из галереи». Для этого скопируйте нужные файлы на телефон или в эмулятор.

Пять разных чеков для пробы:

| Файл | Что видно на изображении |
|---|---|
| `0113e890-ea44-4fad-933b-1ea14eb1b5ef_bin.jpg` | длинный чек с печатью поверх итога и небольшим QR |
| `074c59ba-5c3c-4f02-a646-2a8aa33e7288_bin.jpg` | чек на фактурном фоне, QR внизу |
| `2025-10-21 16.17.59_bin.PNG` | короткий чек с одной позицией и QR |
| `IMG_0667_bin.PNG` | длинный продуктовый чек, QR внизу |
| `IMG_0719_bin.PNG` | чек с одной позицией и QR |

`2c1aeb5e-6b6c-4ae5-ab65-9536270900e7_bin.jpg` — дополнительный длинный чек. `IMG_0720_bin.PNG` и `IMG_0721_bin.PNG` — другие кадры чека из `IMG_0719_bin.PNG`, их нельзя считать отдельными чеками при сравнении.

Файлы являются чёрно-белыми обработанными снимками. Некоторые QR-коды размыты, а форматы строк реальных чеков различаются. Результаты распознавания на них нужно фиксировать после запуска приложения; приведённые изображения сами по себе не доказывают точность распознавания.

Требование этапа 4 об измерениях на **собственных** чеках эти интернет-образцы не заменяют.
